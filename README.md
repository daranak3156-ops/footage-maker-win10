# FootageMaker for Windows 10

Оконная программа собирает черновой MP4 по текстовому сценарию. Она ищет изображения и видео в Wikimedia Commons, нарезает видео и сохраняет сведения об источниках. Дополнительно можно подключить Pexels своим ключом API.

## Готовая сборка

Вкладка **Actions** → **Build Windows 10 application** → последний успешный запуск → **Artifacts** → `FootageMaker_Windows10`. Внутри архива находится папка `FootageMaker`; распакуйте её целиком и запускайте `FootageMaker.exe`. Папки `_internal` и `_ffmpeg` должны оставаться рядом с exe. Для поиска материалов нужен доступ к интернету.

В сборке есть только нейтральный `demo_script.txt`. Свой сценарий храните на компьютере и выбирайте в окне приложения. Сценарий не отправляется в этот репозиторий.

## Работа с программой

1. Выберите текстовый файл сценария и путь для MP4.
2. Нажмите **«Создать план»** и **«Найти кадры»** либо **«Всё автоматически»**.
3. Просмотрите кадры, уточните запрос двойным щелчком или назначьте локальный файл.
4. Нажмите **«Собрать MP4»**. Если есть готовая озвучка, добавьте её перед сборкой.

Пробный монтаж ограничен 12 кадрами. Введите 0, чтобы обработать весь сценарий. Поиск реальных материалов и публикационные права необходимо проверять вручную; источники перечислены в `credits.json` рядом с итоговым видео.

## Сборка из исходников

На Windows установите Python 3.10+ и FFmpeg с ffprobe, затем запустите `build_windows_exe.bat`. Скрипт соберёт переносимую папку `dist/FootageMaker`. Рабочий сценарий и результат сохраняются вне приложения.
